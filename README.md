# 네이버 검색광고 리포트 정리 도구

네이버 **키워드 효율 보고서 CSV**를 업로드하면 월간 리포트 엑셀이 자동 생성됩니다.

---

## 배포판 사용 (권장)

Python 설치 없이 바로 사용:

1. `dist\네이버광고리포트_배포` 폴더 열기
2. **`네이버광고리포트.exe`** 더블클릭
3. 브라우저 → `http://127.0.0.1:8501`

> 폴더 전체를 USB/공유드라이브에 복사해 다른 PC에서도 사용 가능

---

## 개발/수정 시 (실행.bat)

```
실행.bat 더블클릭
```

---

## 배포용 EXE 다시 빌드

코드 수정 후:

```
배포용_빌드.bat 더블클릭
```

결과: `dist\네이버광고리포트_배포\`

---

## CSV 받는 방법

네이버 검색광고 → 보고서 → **키워드 효율 보고서** → 집계 기준별 CSV

| 집계 기준 | 용도 |
|-----------|------|
| 캠페인 | 요약리포트 |
| 키워드(광고그룹+검색어) | 키워드별 |
| 일별 / 요일별 / 주별 | 일자·요일·주차 |
| 지역 / 상세지역 | 지역별 |
| 성별 / 연령 / PC·모바일 | 인구통계 |

---
