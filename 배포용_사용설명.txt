네이버 검색광고 리포트 정리 도구 - 배포판 사용 설명
============================================

■ 실행 방법
  1. "네이버광고리포트.exe" 더블클릭
  2. 2~3초 후 브라우저가 자동으로 열립니다
  3. 주소: http://127.0.0.1:8501
  4. 검은 창(콘솔)은 닫지 마세요 - 닫으면 프로그램이 종료됩니다

■ 브라우저가 안 열리면
  Chrome/Edge 주소창에 입력: http://127.0.0.1:8501

■ 종료 방법
  검은 창에서 Ctrl+C 또는 창 닫기

■ 데이터 저장 위치 (이 폴더 안)
  data\reports\업체명\     ← 저장된 엑셀 리포트
  data\reports.db          ← 전월 대비용 기록

■ 다른 PC에 설치
  이 폴더 전체를 복사하면 됩니다. Python 설치 불필요.

■ 주의
  - Windows 보안 경고가 뜨면 "추가 정보" → "실행"
  - 백신이 차단하면 예외 등록
  - 폴더 경로/파일명은 변경하지 마세요

■ 문의
  시월기획 플랫폼개발팀
